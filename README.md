# Nala's English Learning Workspace V3

## 核心设计原则
- 首页以学习效率、进度和成果转化为核心
- Transcript 删除全部时间戳
- 英文与中文保持左右对照布局
- 每期按照 Transcript → Vocabulary → Shadowing → Speaking → Review 形成学习闭环
- 学习进度和文字回答保存在当前浏览器

## 更新 GitHub Pages
用本压缩包中的 `index.html`、`styles.css`、`app.js` 和 `README.md`
覆盖仓库根目录中的同名文件，然后提交到 main 分支。
