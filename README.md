# Nala's English Learning Workspace V4.2 Ultimate

这是可直接部署到 GitHub Pages 的多页面静态网站。

## 压缩包结构

解压后第一层应直接看到：

- `index.html`
- `library.html`
- `vocabulary.html`
- `progress.html`
- `README.md`
- `.nojekyll`
- `assets/`
- `episodes/`

压缩包内没有额外的最外层项目文件夹。

## GitHub Pages 部署

1. 打开 GitHub 仓库根目录。
2. 删除旧版根目录文件和误上传的外层文件夹。
3. 解压本压缩包。
4. 将解压后第一层的全部文件和文件夹上传到仓库根目录。
5. 在 `Settings → Pages` 中设置：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. 保存并等待部署。

项目站点地址格式：

`https://你的用户名.github.io/仓库名/`

例如：

`https://joshpearl1230-creator.github.io/-nala-english-hub/`
