# Nala's English Learning Hub

这是一个无需安装即可使用的静态英语学习网站。

## 本地打开
双击 `index.html` 即可在浏览器中学习。

## 发布到 GitHub Pages
1. 在 GitHub 新建一个 public repository，例如 `nala-english-hub`
2. 上传本文件夹中的 `index.html`、`styles.css`、`app.js`
3. 打开 Settings → Pages
4. 在 Build and deployment 中选择 Deploy from a branch
5. Branch 选择 `main`，Folder 选择 `/(root)`，保存
6. 等待约 1–3 分钟，GitHub 会显示网站地址

## 后续更新
新的 Culips Transcript 可以继续交给 ChatGPT，更新后重新上传替换网站文件即可。
