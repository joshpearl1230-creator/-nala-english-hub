# Nala's English Learning Workspace V4

这是可直接部署到 GitHub Pages 的多页面静态网站。

## 文件结构

- `index.html`：Dashboard
- `library.html`：Episode Library
- `vocabulary.html`：跨节目词汇与表达库
- `progress.html`：Progress Dashboard
- `episodes/ep294.html`：Catch Word #294
- `episodes/ep350.html`：Chatterbox #350
- `assets/css/styles.css`：统一设计系统
- `assets/js/site.js`：搜索、阅读切换、进度保存、朗读等功能

## 更新 GitHub

最稳妥的方式：

1. 解压本压缩包。
2. 进入 GitHub 仓库。
3. 删除原仓库中旧的 `index.html`、`styles.css`、`app.js`。
4. 点击 **Add file → Upload files**。
5. 将解压后的所有文件和文件夹一起上传，包括：
   - `index.html`
   - `library.html`
   - `vocabulary.html`
   - `progress.html`
   - `episodes` 文件夹
   - `assets` 文件夹
   - `README.md`
6. 提交到 `main` 分支。
7. 等待 GitHub Pages 自动部署，然后强制刷新网站。

注意：不要只上传 ZIP 压缩包，也不要遗漏 `episodes` 或 `assets` 文件夹。
